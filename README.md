# Professional Data Cleaning Project

## Project Objective
To identify, clean, validate and document
data quality issues in a real-world dataset.

## Tools Used
- Python
- Pandas
- NumPy
- Google Colab

## Project Workflow
1. Data collection
2. Data inspection
3. Data quality assessment
4. Data cleaning
5. Data validation
6. Before-and-after comparison
7. Final reporting
